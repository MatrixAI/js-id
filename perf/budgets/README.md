# Performance budgets

This directory owns future budget classes, threshold proposals, waiver rules,
and regression-policy decisions. There are currently no numeric budgets or
release-blocking performance gates.

Before promoting an observation into a budget, require a durable or explicitly
accepted baseline, a validated result and execution profile, repeated runs with
variance, a sufficiently controlled environment, and an explicit decision that
states scope, threshold, authority, and waiver path. Uncontrolled local runs and
harness-health results have no budget or regression-gate authority.
