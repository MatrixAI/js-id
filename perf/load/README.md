# Load evidence

This directory is reserved for reviewed saturation, load, stress, and soak
scenarios and their evidence. The current single-process microbenchmarks do not
establish database locality, distributed capacity, end-to-end throughput, or
production runtime behavior. There are currently no retained load results.

Any future scenario should identify its topology, workload, clocks, node
allocation, duration, execution profile, and limitations, separately from
deterministic correctness tests.
