# Retained results

Keep only reviewed, compact observations here, validated against
[the result schema](schema.json) and accompanied by interpretation explaining
the question, source, provider, execution profile, samples, variance, caveats,
and decision supported. Fresh and throwaway runs stay under `tmp/perf/runs/` or
the Nix check artifact tree.

There are currently no curated results. A locally observed timing, an adapted
historical source, or a passing harness-health check is not a numeric budget,
release gate, or correctness proof.
